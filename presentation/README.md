# Viva presentation

| File | Purpose |
|---|---|
| `Mallick_MSc_Viva_Presentation.pptx` | Editable 16:9 deck: 13 main slides, backup index, 25 backups, speaker notes, native click builds |
| `Mallick_MSc_Viva_Presentation.pdf` | Every slide in its final state |
| `Mallick_MSc_Viva_Presentation.html` | Offline animated deck (open in Chrome or Edge; press O for overview, N for notes) |
| `SPEAKER_NOTES_TIMED_SCRIPT.md` | Timed script, generated from the deck's notes |
| `VERIFICATION_REPORT.md` | Sources, checked claims, tests and limitations |

Rebuild after editing `src/`: `NODE_PATH=<folder containing pptxgenjs> node src/build.js` (then print the HTML to PDF).
